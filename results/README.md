# Local pilot outputs

Generated JSON is intentionally ignored. The local `pilot.json` from the initial
assessment remains available in the workspace. Run the commands in
[CI and delivery](../docs/ci-cd.md) to create new artifacts. Each output records
source/runtime provenance; a dirty base commit alone does not identify a harness.
CI retains complete traces as downloadable Actions artifacts for 30 days.
Publication artifacts still require permanent archival storage.
